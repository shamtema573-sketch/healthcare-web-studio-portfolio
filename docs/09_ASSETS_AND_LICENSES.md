Exact direct dependency versions are pinned in `package.json` and the transitive resolution is recorded in `package-lock.json`. Review current licenses before redistributing or modifying dependencies. Do not copy icon artwork into a new logo.

## Fonts

No web font is fetched from a third-party host, and this repo does not bundle font files. CSS uses system-friendly font stacks with named fallbacks. For client delivery, select and license the final font family, bundle or load it with permission, and retest line breaks and layout.

## Project code and content

No project-level open-source license is granted in this handoff. Confirm the desired reuse terms before publishing a GitHub repository with a license. The theme and front-end code are project-authored; the sample clinic names, staff, service values, and prices are fictional. Replace them with client-approved content before production.

## Reference sites

The URLs in [01_REFERENCE_RESEARCH.md](01_REFERENCE_RESEARCH.md) were inspected for publicly visible information architecture and navigation patterns. Their names, marks, content, photography, and distinctive design expression are not included as project assets.

## Secrets and external requests

The demo forms are local only. They send no personal or medical information. No analytics, remote API, CRM, payment, email, SMS, or appointment integration is included. Do not commit access tokens, `.env` values, or real patient data.
